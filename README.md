# CFM56 Turbofan — experiencia web 3D

Visualización 3D interactiva de un motor turbofan (estilo CFM56) con **Three.js**:
cámara que orbita, despiece de álabes y coreografía animada por tiempo virtual.
Demo técnico de las experiencias 3D que construyo para webs y productos.

## Stack
- **Three.js** (WebGL) — modelo `.obj` + HDRI para iluminación.
- Versión sin build (`index.html` + `script.js`) y variante en **Vite** (`folio-3d/`).

## Cómo verlo en local
```bash
python3 -m http.server 8000
# abre http://127.0.0.1:8000
```
